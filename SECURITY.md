# Security Policy

## Report a vulnerability

Do not report a vulnerability in a public issue, a pull request, or a discussion.

Send an email to security@moia.io. In the email, include:

- A description of the vulnerability.
- The steps to reproduce it.
- The affected version or commit.
- The possible impact.

Do not include real secrets or personal data in the report.

## What happens next

1. The security team receives your report and confirms it.
2. The security team and the owning team assess the risk.
3. The owning team fixes the vulnerability and publishes the fix.
4. The security team tells you when the fix is available.

Please do not publish details of the vulnerability before the fix is available.
